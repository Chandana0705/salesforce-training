# Admin Day 2 - Reports and Dashboards

# What is a Report?

A Report is a list of records that helps users view and analyze data stored in Salesforce.

Reports help us:
- View information
- Filter data
- Find trends
- Track performance

### Example

A report can show:
- All students in a course
- Students with attendance below 75%
- Students with pending fees

### My Understanding

As a beginner, I understood that reports help us organize and analyze data in a meaningful way.

---

# What is a Dashboard?

A Dashboard is a visual representation of report data.

Dashboards display information using:
- Charts
- Graphs
- Tables
- Metrics

### Example

A college dashboard can show:
- Total students
- New admissions
- Fee collection status
- Attendance statistics

### My Understanding

A dashboard helps users quickly understand important information without reading detailed reports.

---

# Difference Between Reports and Dashboards

| Report | Dashboard |
|----------|-----------|
| Shows detailed data | Shows visual summary |
| Can contain many records | Uses charts and graphs |
| Used for analysis | Used for quick insights |
| Data in table format | Data in visual format |

### My Understanding

Reports provide detailed information, while dashboards provide a quick overview of that information.

# Five Important College Reports

## 1. Student Admission Report

Shows:
- Student Name
- Course
- Admission Date

Purpose:
- Track admissions.

---

## 2. Attendance Report

Shows:
- Student Name
- Attendance Percentage

Purpose:
- Identify students with low attendance.

---

## 3. Fee Collection Report

Shows:
- Paid Fees
- Pending Fees

Purpose:
- Monitor fee payments.

---

## 4. Faculty Report

Shows:
- Faculty Name
- Assigned Courses

Purpose:
- Track faculty workload.

---

## 5. Course Enrollment Report

Shows:
- Course Name
- Number of Students Enrolled

Purpose:
- Monitor course popularity.
