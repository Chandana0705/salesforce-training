# Day 17 - Agentforce and AI

# Agentforce Summary

Agentforce is Salesforce's AI platform that helps organizations create AI agents that can perform tasks, answer questions, and assist users automatically.

These AI agents can work with Salesforce data and help improve productivity.

### My Understanding

As a beginner, I understood that Agentforce allows businesses to use AI agents to handle tasks that normally require human effort.

---

# AI Agent Use Cases

## 1. Student Admission Assistant

An AI agent can answer questions about:
- Admissions
- Courses
- Eligibility criteria

---

## 2. Student Support Agent

An AI agent can help students find:
- Attendance information
- Fee details
- Course schedules

---

## 3. Faculty Support Agent

An AI agent can provide:
- Student information
- Course details
- Attendance reports

---

## 4. Fee Inquiry Agent

Students can ask:
- Fee amount
- Due dates
- Payment status

The AI agent can provide instant responses.

---

## 5. Help Desk Agent

An AI agent can answer common questions without requiring human support staff.

# AI Workflow Explanation

### Example: Student Admission Inquiry

```text
Student Asks Question
          |
          v
AI Agent Receives Request
          |
          v
Agent Searches Salesforce Data
          |
          v
Agent Generates Response
          |
          v
Student Receives Answer
```

### Example

Student asks:

```text
What is my attendance percentage?
```

The AI agent:
1. Retrieves student data.
2. Checks attendance records.
3. Returns the attendance percentage.

### My Understanding

The AI agent acts like a virtual assistant that can access information and provide answers automatically.

# Risks of Enterprise AI

While AI provides many benefits, there are also some risks.

## Incorrect Answers

AI may sometimes provide inaccurate information.

---

## Data Privacy Concerns

Sensitive information must be protected.

---

## Security Risks

Unauthorized access to data can create problems.

---

## Overdependence on AI

Organizations should not rely completely on AI for important decisions.

---

## Bias and Errors

AI systems may generate incorrect or biased results if the data is not properly managed.

### My Understanding

AI is helpful, but organizations must use it carefully and monitor its outputs.
